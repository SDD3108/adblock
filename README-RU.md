# Личное расширение с оформлением AdBlock

Это самостоятельно созданный помощник Gemini. Он не является официальным AdBlock и не блокирует рекламу. Название, описание и версия в manifest.json повторяют данные заказчика; иконка взята с официального сайта AdBlock. Не предназначено для публикации в магазине или распространения от имени AdBlock.

## Установка

1. Распакуй ZIP. Внутри находится папка adblock-personal.
2. Открой config.js в редакторе кода (например, VS Code). В строке ниже замени PASTE_YOUR_API_KEY_HERE своим ключом, сохранив кавычки:

   ```js
   export const API_KEY = 'PASTE_YOUR_API_KEY_HERE'
   ```

3. Сохрани файл. Открой chrome://extensions, включи режим разработчика и загрузи папку adblock-personal, в которой находится manifest.json.
4. Если расширение уже установлено из этой папки, нажми «Обновить» на его карточке после замены файлов. Для новой папки удали старую сборку и загрузи новую, чтобы не было двух одинаковых расширений.
5. Закрепи иконку через меню расширений Chrome. Вводить ключ в окне настроек не нужно. Через шестерёнку можно изменить модель и инструкцию.
6. Открой chrome://extensions/shortcuts. Проверь, что назначено Command+Shift+S на Mac (Ctrl+Shift+S на Windows/Linux). Если есть конфликт, назначь сочетание вручную.

При любой замене ключа в config.js сохраняй файл и обновляй расширение в chrome://extensions.

## Использование

Открой обычный сайт, нажми ⇧⌘S, зажми левую кнопку мыши и выдели область. После отпускания кнопки фрагмент автоматически отправляется в Gemini. Открой иконку расширения и нажми «?» вверху: откроется раздел с результатом. Кнопка «← Назад» или Esc возвращает главный экран. Каждое новое открытие окна начинается с имитации AdBlock; готовый ответ не переключает экран автоматически. Окно можно закрывать во время обработки. Для нескольких вопросов включи их все в выделение. Кнопка «Копировать» копирует ответ. Esc отменяет выделение. Повторное нажатие сочетания также отменяет выделение, если событие обрабатывает Chrome.

Отправляется изображение видимой области, а не текст всей страницы. Не прокручивай страницу и не переключай вкладку во время захвата. Смена размера окна, прокрутка и потеря фокуса отменяют выделение. На Retina и при обычном масштабировании Chrome учитывается соотношение размеров снимка и окна.

## Ключ, данные и доступ

- Project name, project number и ID оригинального AdBlock не нужны.
- В архиве находится только заглушка для ключа. Вставь свой ключ в config.js самостоятельно.
- Ключ читается напрямую из config.js и не сохраняется расширением в chrome.storage.local. Ранее сохранённый через настройки ключ удаляется при запуске новой сборки. Тот, у кого есть доступ к папке расширения, сможет прочитать ключ.
- Контент-скрипт не получает ключ. Доступ к локальному хранилищу ограничен доверенными страницами расширения.
- В Google уходит только обрезанный фрагмент и инструкция из настроек. Полный скриншот обрабатывается локально и не сохраняется на диск расширением.
- Последний ответ хранится в chrome.storage.session и исчезает после перезапуска браузера, перезагрузки расширения или нажатия «Очистить».
- Нет аналитики, своего сервера, внешних библиотек или фонового мониторинга страниц.
- Разрешения: activeTab — временный доступ по нажатию; scripting — рамка выделения; storage — настройки/ответ; offscreen — обработка изображения при закрытом popup. Сетевой доступ: только generativelanguage.googleapis.com.

## Ограничения и ошибки

Нужен Chrome 116+. Chrome назначает отдельный ID; ID настоящего AdBlock не копируется. Расширение не скрывается из списка установленных расширений.

Нельзя выделять на chrome://, Chrome Web Store, страницах других расширений и во встроенном просмотрщике PDF Chrome. Для файла или PDF открой нужную страницу через обычный веб-сайт с HTML-просмотрщиком. Захватывается только видимая часть текущей вкладки.

Модель по умолчанию: gemini-3.8-flash. Список моделей и доступность меняются: используй «Загрузить доступные модели» или введи доступное имя вручную. Список подтверждает доступ к каталогу; конкретный запрос может требовать отдельной квоты/доступа. Нужна модель с поддержкой изображений на входе и текста на выходе.

400/401: проверь ключ и модель. 403: доступ, регион или ограничения ключа. 404: замени модель. 429: квота или частота запросов. 503: повтори позже. Автоматических повторов платных запросов нет. Один запрос обрабатывается до 2 минут. Gemini может ошибаться: сверяй ответы.

## Исходники и источники

Все исходники находятся в этой папке. Manifest V3, без сборщика и зависимостей.

- Иконка: https://getadblock.com/images/favicon.ico (ссылка обнаружена на https://getadblock.com/en/). Права на бренд и иконку принадлежат их владельцам.
- Chrome commands: https://developer.chrome.com/docs/extensions/reference/api/commands
- Chrome offscreen: https://developer.chrome.com/docs/extensions/reference/api/offscreen
- Gemini images: https://ai.google.dev/gemini-api/docs/image-understanding
- Gemini models: https://ai.google.dev/gemini-api/docs/models

## Проверки сборки

Проверены синтаксис JavaScript, ссылки manifest.json, сочетание клавиш, расчёт обрезки на Retina, границы изображения, отправка только обрезанного фрагмента, извлечение ответа и обработка API-ошибок 400/403/404/429/503 на тестовых ответах. Реальный запрос Gemini с пользовательским ключом и установка в Chrome в этой среде не проверялись.

## Главный экран

Оформление повторяет предоставленный референс: домен активной вкладки, баннер VPN, блок статистики и кнопка паузы. Значения счётчиков декоративные (0 и 25,041), блокировка рекламы и VPN не реализованы. Pause/Resume меняет только внешний вид кнопки до закрытия окна. Learn More показывает локальное информационное окно. «?» переключает раздел ответов, шестерёнка открывает настройки.

При обновлении замени файлы в установленной папке, сохранив свой существующий config.js с ключом. Затем нажми «Обновить» в chrome://extensions. В ZIP находится config.js с заглушкой.

## Компактное оформление

Ширина окна — 320 CSS-пикселей. Уменьшены шрифты, логотип, иконки, отступы и высота карточек. Раздел ответов использует ту же ширину, длинный ответ прокручивается внутри окна.
